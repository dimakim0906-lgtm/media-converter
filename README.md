# media-converter

Конвертер медиаформатов «всё во всё» — локальный инструмент для конвертации
картинок, видео и аудио. Ничего не загружается в интернет, вся обработка
происходит на вашем компьютере.

## 📥 Скачать готовое приложение (Windows)

Скачивать и устанавливать Python не нужно — просто заберите готовый `.exe`:

**➡️ [Скачать MediaConverter.exe (последний релиз)](../../releases/latest)**

Запустите файл двойным кликом. Если Windows покажет предупреждение
«Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае»
(это стандартное сообщение для неподписанных программ от небольших разработчиков).

## Возможности

- **Картинки**: HEIC/HEIF, JPG, PNG, WEBP, BMP, TIFF, GIF
- **Аудио**: MP3, WAV, FLAC, AAC, OGG, M4A и др.
- **Видео**: MP4, MOV, MKV, WEBM, AVI и др.
- Перетаскивание файлов (drag & drop) в окне программы
- Пакетная конвертация нескольких файлов сразу

## Как пользоваться

1. Откройте приложение.
2. Перетащите файлы в окно (или нажмите «Добавить файлы»).
3. Выберите формат назначения.
4. Нажмите «Конвертировать».

**Для видео и аудио** дополнительно нужен `ffmpeg`. Если конвертация видео/аудио
выдаёт ошибку — скачайте `ffmpeg.exe` (например, с
[gyan.dev/ffmpeg/builds](https://www.gyan.dev/ffmpeg/builds/), раздел "release essentials")
и положите его в ту же папку, где лежит `MediaConverter.exe`.

## Для разработчиков

Исходный код лежит в этом репозитории (`gui.py`, `cli.py`, `converter_core.py`).
Есть также консольная версия (`cli.py`) для запуска без графического интерфейса.

Сборка `.exe` происходит автоматически через GitHub Actions
(см. `.github/workflows/main.yml`) при каждом push в ветку `main`.
Готовый файл появляется во вкладке **Actions** (Artifacts) и публикуется
в **Releases**.

```bash
pip install -r requirements.txt
python gui.py     # графический интерфейс
python cli.py photo.heic photo.jpg   # командная строка
```
